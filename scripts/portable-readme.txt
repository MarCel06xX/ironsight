Ironsight - portable version
============================

English
-------
- Unzip this folder anywhere (for example on a USB stick) and run Ironsight.exe.
  No installation needed.
- Because of the empty file "portable" next to Ironsight.exe, the settings and the
  WebView2 profile are stored in the "data" folder next to the exe - nothing goes to
  AppData. If "data" cannot be written, Ironsight uses the normal AppData folders instead.
  Delete "portable" to always use AppData.
- Requires Windows 10/11 (x64) with the Microsoft Edge WebView2 runtime. It is part of
  Windows 11; on Windows 10 install it from
  https://developer.microsoft.com/microsoft-edge/webview2/
- Ironsight.exe is not code-signed, so Windows SmartScreen may show a warning. Compare the
  zip file with SHA256SUMS.txt from the release page.
- Only scan networks you own or are explicitly authorized to scan.

- Source code: https://github.com/MarCel06xX/ironsight

Deutsch
-------
- Diesen Ordner an einen beliebigen Ort entpacken (z. B. auf einen USB-Stick) und
  Ironsight.exe starten. Keine Installation nötig.
- Wegen der leeren Datei "portable" neben Ironsight.exe werden die Einstellungen und das
  WebView2-Profil im Ordner "data" neben der exe gespeichert - nichts landet in AppData.
  Ist "data" nicht beschreibbar, nutzt Ironsight stattdessen die normalen AppData-Ordner.
  "portable" löschen, um immer AppData zu verwenden.
- Benötigt Windows 10/11 (x64) mit der Microsoft Edge WebView2 Runtime. Sie ist Teil von
  Windows 11; unter Windows 10 gibt es sie unter
  https://developer.microsoft.com/microsoft-edge/webview2/
- Ironsight.exe ist nicht signiert, daher kann Windows SmartScreen warnen. Die zip-Datei
  mit SHA256SUMS.txt von der Release-Seite vergleichen.
- Scanne nur Netzwerke, die dir gehören oder für die du ausdrücklich eine Erlaubnis hast.
- Lizenz: MIT OR Apache-2.0 (siehe LICENSE-MIT und LICENSE-APACHE).
- Quellcode: https://github.com/MarCel06xX/ironsight
