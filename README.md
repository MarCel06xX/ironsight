# Ironsight

Open-source desktop network scanner for Windows, built with Rust and Tauri 2.
v1 scope: host discovery, device info and export. Work in progress.

> Only scan networks you own or are explicitly authorized to scan.

## Development

Requirements: Rust (stable, MSVC), MSVC Build Tools, Node.js LTS.

```
npm install
npm run tauri dev
```
